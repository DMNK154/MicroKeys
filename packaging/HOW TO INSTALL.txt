MicroKeys @VERSION@ for Windows (64-bit)
========================================

MicroKeys is a microtonal instrument: you can tune every key of your keyboard
individually. It comes as a VST® 3 plugin (for FL Studio and other music
software) and as a standalone app that runs on its own.

Website and source code: https://github.com/DMNK154/MicroKeys


THE EASY WAY: THE INSTALLER
---------------------------
1. Run MicroKeys-@VERSION@-Windows-Setup.exe.

   Windows may show "Windows protected your PC". This appears because the
   installer is not signed with a paid certificate. Click "More info", then
   "Run anyway".

2. Click through the installer. It puts:
   - the VST3 plugin in C:\Program Files\Common Files\VST3
   - the standalone app in the Start menu
   - the tunings in your Documents\MicroKeys Scales folder
     (tunings you already have there are never overwritten)


THE PORTABLE ZIP (NO INSTALLER)
-------------------------------
1. Unzip MicroKeys-@VERSION@-Windows.zip.
2. Copy the "MicroKeys.vst3" folder into C:\Program Files\Common Files\VST3
   (Windows will ask for permission).
3. Copy the "MicroKeys Scales" folder into your Documents folder.
4. MicroKeys.exe is the standalone app; you can run it from anywhere.


USING IT IN FL STUDIO
---------------------
1. Options > Manage plugins > Find installed plugins.
2. MicroKeys appears under Generators. Add it to a channel like any instrument.


USING THE STANDALONE APP
------------------------
1. Start MicroKeys from the Start menu (or run MicroKeys.exe).
2. Click "Options" at the top left, then "Audio/MIDI Settings...".
3. Pick your audio output, and tick your MIDI keyboard under "Active MIDI
   inputs". MicroKeys remembers this for next time.

You can also play by clicking the keys on screen. Some MIDI keyboards can
only be used by one program at a time, so if FL Studio is open and using
yours, close FL Studio first.


LOADING A TUNING
----------------
Click "Load scale..." in MicroKeys and pick a file. The dialog opens in the
folder you last saved to or loaded from; the first time, that is
Documents\MicroKeys Scales.
- .mkscale files are complete tunings: every key at its exact pitch.
- .scl files are Scala scales (see IMPORTING A SCALA SCALE below).

To tune a key yourself: play or click it, then drag the cents slider, or type
an exact frequency in Hz into the box for that key and press Enter. The Hz
boxes show one octave at a time; choose another with the Octave menu or the
< and > buttons beside it.

Keys per octave: "Tune all octaves" (on by default) copies each change to
the same key in every octave. If your layout takes more or fewer keys than a
piano to reach the octave, for example 24 for quarter tones, choose that
number from the "Keys per octave" menu next to the key's frequency first.
Changing it does not retune anything; it only tells "Tune all octaves" which
keys are octaves of each other. When it isn't 12, those keys are tinted
orange on the keyboard. The Hz boxes still show 12 piano keys at a time.
"Reset all" puts every key back to standard tuning with 12 keys per octave.


IMPORTING A SCALA SCALE
-----------------------
MicroKeys plays Scala .scl scales, the standard microtonal scale format.
Three classic scales are included in Documents\MicroKeys Scales\Examples.
Thousands more are in the Scala scale archive, which downloads as a zip
file: https://www.huygens-fokker.org/docs/scales.zip
Right-click the zip, choose "Extract All...", and extract it into
Documents\MicroKeys Scales.

Importing, like "Reset all", replaces the tuning of every key, with no
undo. If you have tuned keys you want to keep, click "Save scale..." first.

1. Play or click the key where the scale's 1/1 should go (the root). The
   root is the last key selected: every note MicroKeys receives selects its
   key, including notes your DAW plays back, so stop playback first. When
   MicroKeys first opens, A4 is selected.
   MicroKeys calls middle C (MIDI note 60) C4; FL Studio calls it C5.
2. The 1/1 keeps that key's current pitch, even one left over from a scale
   you loaded before. For the key's standard piano pitch, click "Reset all"
   (the key stays selected). For another pitch, type it into the key's Hz
   box and press Enter.
3. Click "Load scale..." and choose the .scl file. To try it out, go to
   Documents\MicroKeys Scales\Examples and choose
   ptolemy_intense_diatonic.scl.
4. A message confirms the scale, its period and where the root landed.
5. Play upward from the root one key at a time, black and white keys
   alike. Each key is the next degree: a 7-note scale on C4 reaches its
   octave at G4, not C5.

All 128 keys are retuned, and the scale repeats at its own period, which
need not be an octave. If the scale repeats at an exact octave with 5, 6,
7, 12, 19, 22, 24 or 31 notes, Keys per octave is set to match. For other
scales, turn off "Tune all octaves" before adjusting single keys.

The cents slider still measures each key from its standard piano pitch, not
from the scale's 1/1, so after an import many keys read hundreds of cents.
For big changes, type the Hz, then fine-tune with the slider. Use
"Save scale..." to keep your edited version as a .mkscale file.

Not supported: Scala keyboard mapping (.kbm) files (so a 7-note scale can't
go on the white keys only), MTS-ESP, MIDI Tuning Standard messages, .tun
files, and exporting .scl files. The tuning changes only MicroKeys' own
sound.

The .scl files in "Scala files" are this project's guitar tunings as 3- to
11-note scales. guitar3.scl to guitar8.scl have 6 notes per octave, one per
string, so importing one sets Keys per octave to 6. To play a guitar tuning
with each string on its own piano key, load its .mkscale file instead.

More detail: https://github.com/DMNK154/MicroKeys#importing-scala-scales

UNINSTALLING
------------
Settings > Apps > Installed apps > MicroKeys > Uninstall.
Your tunings in Documents\MicroKeys Scales are kept.
